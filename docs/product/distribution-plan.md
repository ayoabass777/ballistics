# Distribution plan: international break and wave 2

Recorded 2026-11-05. State: **proposed** (from owner strategy conversation). Extends the [beta recruitment playbook](beta-recruitment.md); its outreach rules still apply (no localhost URLs, follow subreddit rules, no bulk DMs or cross-posting).

## Context

- Beta wave 1 is live with invited users.
- Goal: more users. Distribution is the binding constraint, not features.
- A two-week international break pauses club football, so there are no weekend fixtures to forecast.

## Position: don't wait, don't go loud

Use the break to prepare. Club football returning is the launch moment for wave 2. The moat is the public, timestamped, calibrated track record, so lead with it.

## Week 1: learn from wave 1

- Pull wave 1 numbers from [beta analytics](beta-analytics.md): invited → accepted → first run → league saved → first Match opened → first save → return visit after kickoff.
- **Key number:** how many came back for a second weekend.
- Run 15-minute interviews with 5 wave 1 users:
  - What made you open it last weekend?
  - What did you ignore?
  - Would you be annoyed if it disappeared?
  - Who would you send it to?
- Fix the top 1–2 friction points only. Don't add new features during the break.
- Decision gate: if retention is weak, the break goes to fixing. If it's strong, it goes to scaling.

## Week 2: turn wave 1 into distribution

- Ask the happiest users for one quotable line each, with permission to publish it.
- Give each wave 1 user 2–3 personal invite links for wave 2. Per D156, codes stay bound to an email, so referrals go through the invite flow, not public codes.
- Publish track-record content: calibration chart, Brier score vs. a naive baseline, hits and misses since launch. Point it to a wave 2 waitlist.
- Tease the return weekend: "Picks freeze pre-kickoff. Public, timestamped, no edits."

## Return weekend: open wave 2

- Admit referrals and waitlist users.
- Post frozen picks before kickoff.
- Post results honestly on Monday, misses included.
- Repeat every weekend. Consistency is the marketing.

## Channels (pick 2)

| Platform | Role | Approach |
|---|---|---|
| X (primary) | Football analytics audience | Weekend picks thread, calibration charts, replies to stats accounts, build in public |
| Reddit (primary) | Bettors and stats enthusiasts | Methodology posts that are useful on their own. Link only where rules allow |
| TikTok/Shorts | Later reach | Short clips of form gauges, only once X and Reddit run routinely |
| LinkedIn | Builder story | One post per milestone. Doubles as job-search signal |
| Dev.to | Technical credibility | Calibration deep-dive |

## Paid ads: not yet

- In beta, conversion and retention are unknown, so ads would amplify a leaky funnel.
- Betting-adjacent content is restricted on Meta and Google ads and may need gambling authorization, even though Ballistics frames itself as research.
- Rule: $0 on ads until week-1 return rate is acceptable. After that, a small Reddit or X test.

## Success metric

Wave 2 signups who return the second weekend.
